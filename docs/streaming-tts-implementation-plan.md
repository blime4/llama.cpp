# Streaming TTS Implementation Plan

## Project Overview

### Goal
Convert the current non-streaming TTS implementation to a streaming architecture where audio tokens are decoded incrementally as they are generated by the LLM, enabling low-latency real-time audio output.

### Current State (Updated: 2026-03-10)
- **Location:** `tools/tts/orpheus-tts.cpp`, `tools/tts/snac-ggml.h`, `tools/tts/snac-ggml.cpp`
- **Mode:** Non-streaming (wait for all tokens, decode once, save file)
- **Performance:** GGML CPU = 0.08x real-time (12x faster than real-time)
- **Audio Quality:** ZCR 0.08-0.20 ✓ GOOD (updated for SNAC vocoder)

### Target State
- **Mode:** Streaming (incremental decode as tokens arrive)
- **Latency:** First audio chunk < 2 seconds from generation start
- **Quality:** Identical to non-streaming (ZCR 0.08-0.20)
- **Interface:** Callback-based audio output

## Architecture Design

### Current (Non-Streaming) Flow
```
+-------------------+     +------------------+     +------------------+
|   LLM Generation  |     |  Collect All     |     |   Save WAV       |
|   (All Tokens)    |---->|  Tokens          |---->|   File           |
+-------------------+     +------------------+     +------------------+
                                  |
                                  v
                          +---------------+
                          |  SNAC Decode  |
                          |  (All at Once)|
                          +---------------+
```

### Target (Streaming) Flow
```
+-------------------+
|   LLM Generation  |
|   (Token-by-Token)|
+-------------------+
          |
          v
+-------------------+     +------------------+
|   Token Buffer    |     |  Frame Boundary  |
|   (Accumulate)    |---->|  Detection       |
+-------------------+     +------------------+
          |                       |
          v (when chunk ready)    |
+-------------------+             |
|   SNAC Decode     |<------------+
|   (Chunk)         |
+-------------------+
          |
          v
+-------------------+     +------------------+
|   Crossfade       |     |  Audio Callback  |
|   (Overlap)       |---->|  / Stream Output |
+-------------------+     +------------------+
```

### SNAC Pyramid Token Structure

```
Frame Size: 7 tokens
Structure: [head0, head1, head2, head2, head1, head2, head2]

Position:  |  0  |  1  |  2  |  3  |  4  |  5  |  6  |
Head:      |  0  |  1  |  2  |  2  |  1  |  2  |  2  |

VQ Strides: [4, 2, 1]
- head0: 1 token/frame (repeats 4x in output)
- head1: 2 tokens/frame (repeat 2x each)
- head2: 4 tokens/frame (no repeat)

Output per frame: 4 * 512 = 2048 PCM samples
```

### Chunk Overlap Strategy

```
Chunk Layout:
+----------+------------------+----------+
| Overlap  |   Output Region  | Overlap  |
| (4 frames)|   (8 frames)    | (4 frames)|
+----------+------------------+----------+
     ^                               ^
     |                               |
     +--- Crossfade with previous ---+
     +--- Saved for next chunk ------+

Crossfade:
- Blend last 256 samples of previous chunk with first 256 of current
- Linear interpolation: output = (1-α)*prev + α*curr
```

```cpp
// Streaming token buffer - accumulates tokens until frame boundary
struct snac_streaming_buffer {
    // Pyramid token buffers for each head
    std::vector<int> head0_tokens;  // Quantizer 0 tokens
    std::vector<int> head1_tokens;  // Quantizer 1 tokens
    std::vector<int> head2_tokens;  // Quantizer 2 tokens

    // Frame accumulation state
    int frame_position = 0;  // Current position in frame (0-6)

    // Pyramid mapping: position -> which head this token belongs to
    static constexpr int PYRAMID_MAP[7] = {0, 1, 2, 2, 1, 2, 2};

    // Token value constants
    static constexpr int CODEBOOK_SIZE = 4096;

    // Statistics
    int total_frames_completed = 0;

    // Methods
    void reset();
    bool add_token(int raw_token);  // Returns true if frame completed
    bool has_frames(int n) const;
    std::vector<std::vector<int>> get_completed_frames(int max_frames = -1) const;
    void consume_frames(int n_frames);
};
```

#### Task 1.2: Implement Token Buffer Logic
**File:** `tools/tts/snac-ggml.cpp`

**Action:** Implement streaming buffer methods:

```cpp
void snac_streaming_buffer::reset() {
    head0_tokens.clear();
    head1_tokens.clear();
    head2_tokens.clear();
    frame_position = 0;
    total_frames_completed = 0;
}

bool snac_streaming_buffer::add_token(int raw_token) {
    int head = PYRAMID_MAP[frame_position];
    int token_value = raw_token - (frame_position * CODEBOOK_SIZE);

    if (token_value < 0 || token_value >= CODEBOOK_SIZE) {
        token_value = 0;
    }

    switch (head) {
        case 0: head0_tokens.push_back(token_value); break;
        case 1: head1_tokens.push_back(token_value); break;
        case 2: head2_tokens.push_back(token_value); break;
    }

    frame_position++;
    bool frame_completed = (frame_position >= 7);
    if (frame_completed) {
        frame_position = 0;
        total_frames_completed++;
    }
    return frame_completed;
}

bool snac_streaming_buffer::has_frames(int n) const {
    return total_frames_completed >= n;
}

std::vector<std::vector<int>> snac_streaming_buffer::get_completed_frames(int max_frames) const {
    std::vector<std::vector<int>> result(3);
    int n = (max_frames < 0) ? total_frames_completed :
            std::min(max_frames, total_frames_completed);

    result[0].assign(head0_tokens.begin(), head0_tokens.begin() + n);
    result[1].assign(head1_tokens.begin(), head1_tokens.begin() + n * 2);
    result[2].assign(head2_tokens.begin(), head2_tokens.begin() + n * 4);

    return result;
}

void snac_streaming_buffer::consume_frames(int n_frames) {
    if (n_frames <= 0 || n_frames > total_frames_completed) return;

    head0_tokens.erase(head0_tokens.begin(), head0_tokens.begin() + n_frames);
    head1_tokens.erase(head1_tokens.begin(), head1_tokens.begin() + n_frames * 2);
    head2_tokens.erase(head2_tokens.begin(), head2_tokens.begin() + n_frames * 4);
    total_frames_completed -= n_frames;
}
```

```cpp
struct streaming_callback_ctx {
    std::vector<float> * all_samples;
    std::string output_path;
    int chunks_received = 0;
    FILE * raw_output = nullptr;
};

static bool streaming_audio_callback(
    const float * pcm_data,
    int num_samples,
    void * user_data
) {
    auto * ctx = static_cast<streaming_callback_ctx *>(user_data);

    if (ctx->all_samples) {
        ctx->all_samples->insert(ctx->all_samples->end(),
                                  pcm_data, pcm_data + num_samples);
    }

    ctx->chunks_received++;

    float duration = (float)num_samples / SNAC_SAMPLE_RATE;
    LOG_INF("Streaming chunk %d: %d samples (%.2fs)\n",
            ctx->chunks_received, num_samples, duration);

    return true;
}
```

#### Task 4.1: Create ZCR Quality Test Script
**File:** `test_streaming_quality.py`

**Action:** Create Python validation script:

```python
#!/usr/bin/env python3
"""
Test streaming TTS quality against non-streaming baseline.
"""

import numpy as np
import wave
import subprocess
import sys

SAMPLE_RATE = 24000
ZCR_MIN = 0.08
ZCR_MAX = 0.20

def load_wav(path):
    with wave.open(path, 'rb') as wf:
        frames = wf.getnframes()
        raw = wf.readframes(frames)
        samples = np.frombuffer(raw, dtype=np.int16).astype(np.float32) / 32768.0
    return samples

def compute_zcr(samples):
    crossings = np.sum(np.abs(np.diff(np.sign(samples))) > 0)
    return crossings / len(samples)

def test_streaming_quality():
    print("="*60)
    print("Streaming TTS Quality Test")
    print("="*60)

    text = "Hello, this is a test of the streaming text to speech system."

    # Generate non-streaming baseline
    print("\n[1/3] Generating non-streaming baseline...")
    subprocess.run([
        './bin/llama-orpheus-tts',
        '-m', 'models/orpheus-3b-f16.gguf',
        '--model-vocoder', 'models/snac-24khz-f16.gguf',
        '-p', text,
        '-o', '/tmp/baseline.wav',
        '--use-snac-ggml'
    ], check=True)

    baseline = load_wav('/tmp/baseline.wav')
    baseline_zcr = compute_zcr(baseline)
    print(f"  Baseline: {len(baseline)} samples, ZCR={baseline_zcr:.4f}")

    # Generate streaming output
    print("\n[2/3] Generating streaming output...")
    subprocess.run([
        './bin/llama-orpheus-tts',
        '-m', 'models/orpheus-3b-f16.gguf',
        '--model-vocoder', 'models/snac-24khz-f16.gguf',
        '-p', text,
        '-o', '/tmp/streaming.wav',
        '--use-snac-ggml',
        '--streaming'
    ], check=True)

    streaming = load_wav('/tmp/streaming.wav')
    streaming_zcr = compute_zcr(streaming)
    print(f"  Streaming: {len(streaming)} samples, ZCR={streaming_zcr:.4f}")

    # Validate
    print("\n[3/3] Validating quality...")
    all_pass = True

    # ZCR checks
    for name, zcr in [("Baseline", baseline_zcr), ("Streaming", streaming_zcr)]:
        if ZCR_MIN <= zcr <= ZCR_MAX:
            print(f"  [PASS] {name} ZCR ({zcr:.4f}) in range [{ZCR_MIN}, {ZCR_MAX}]")
        else:
            print(f"  [FAIL] {name} ZCR ({zcr:.4f}) outside range")
            all_pass = False

    # Correlation check
    min_len = min(len(baseline), len(streaming))
    correlation = np.corrcoef(baseline[:min_len], streaming[:min_len])[0, 1]
    if correlation > 0.95:
        print(f"  [PASS] Correlation: {correlation:.4f}")
    else:
        print(f"  [FAIL] Correlation too low: {correlation:.4f}")
        all_pass = False

    # Length check
    len_ratio = len(streaming) / len(baseline)
    if 0.95 <= len_ratio <= 1.05:
        print(f"  [PASS] Length ratio: {len_ratio:.4f}")
    else:
        print(f"  [FAIL] Length ratio: {len_ratio:.4f}")
        all_pass = False

    print("\n" + "="*60)
    print("ALL TESTS PASSED" if all_pass else "SOME TESTS FAILED")
    return all_pass

if __name__ == "__main__":
    success = test_streaming_quality()
    sys.exit(0 if success else 1)
```

- [ ] First audio chunk < 2 seconds from generation start
- [ ] Callback interface works correctly
- [ ] Flush outputs remaining audio properly

### Quality Requirements
- [ ] ZCR in range 0.08-0.20 (same as non-streaming)
- [ ] Streaming/non-streaming correlation > 0.95
- [ ] No audible artifacts at chunk boundaries
- [ ] Long audio (>10s) maintains quality throughout

### Performance Requirements
- [ ] No memory leaks over extended generation
- [ ] CPU overhead < 10% vs non-streaming
- [ ] First chunk latency < 2s from start
